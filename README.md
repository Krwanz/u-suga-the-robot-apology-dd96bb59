A make.fun bounty entry: [The Robot Apology](https://make.fun/c/u-suga-the-robot-apology-dd96bb59).

A two-line robot confession: the first sentence owns one specific mistake,
the second names the lesson it taught and what the robot will do differently.
`main.py` writes the confession to `/output/entry.txt`.
